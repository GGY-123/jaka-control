# ADP 移液空气泵 RS485 控制方案

## 1. 方案目标

电脑通过 RS485 控制 ADP 移液空气泵完成两个动作：

1. 电脑发送指令后，移液器吸入 0.6 mL 液体。
2. 电脑分 3 次发送排液指令，每次排出 0.2 mL。

0.6 mL 对应 `600 uL`，每次 0.2 mL 对应 `200 uL`。

## 2. 推荐通信方式

RS485 是电气层接口，ADP 手册中提供两种 RS485 应用协议：

- ASCII：格式直观，适合手动调试，也是随附调试软件日志中出现的协议。
- Modbus-RTU：更标准，适合后续接入工控上位机。

本方案采用 ASCII 协议，并提供 Python 控制脚本。手册 FAQ 推荐 RS485 Modbus，但两个协议在 ADP 上能力相同；如果你已有 Modbus 主站，也可以按文末寄存器表实现。

## 3. 所需硬件

- ADP5ML 或 ADP10ML 移液空气泵 1 台。
- DC24V 稳压电源，建议电流 2A 以上。
- USB 转 RS485 模块 1 个。
- 5mL 或 10mL 适配 Tip。
- 电脑、USB 线、双绞屏蔽线若干。

## 4. 接线

ADP5ML/ADP10ML 使用 7 芯电缆：

| Pin | 颜色 | 标识 | 连接 |
|---|---|---|---|
| 1 | 红 | VCC | DC24V+ |
| 2 | 黑 | GND | 电源 0V，并与 USB-RS485 GND 共地 |
| 3 | 棕 | 485A | USB-RS485 A |
| 4 | 蓝 | 485B | USB-RS485 B |
| 5 | 白 | LEVEL | 液面信号，可选 |
| 6 | 绿 | CAN_H | 本方案不接 |
| 7 | 黄 | CAN_L | 本方案不接 |

检查事项：

- 485A/485B 不要接反。
- 电脑电源地与移液器电源地建议共地，否则可能通信不稳定。
- RS485 总线较短时可先不接终端电阻；如果通信异常，可在总线两端尝试 120 Ω 终端电阻。
- 上电顺序：先接好线，再给 ADP 上电，最后打开串口程序。

## 5. 通信参数

- 串口：实际 COM 口，例如 `COM5`
- 波特率：`115200`
- 数据位：`8`
- 校验位：`无`
- 停止位：`1`
- 设备地址：默认 `01`；如果设备已被改成其他地址，使用对应地址
- 通信模式：半双工，一问一答，发送下一帧前等待上一帧响应

## 6. Python 脚本

当前脚本：

- [adp_rs485_check.py](./adp_rs485_check.py)：只查询软件版本，不执行动作。
- [adp_rs485_interactive.py](./adp_rs485_interactive.py)：在终端中按命令执行吸液和排液。

先安装依赖：

```powershell
python -m pip install pyserial
```

### 通信检查

设备 ID 为 `02`：

```powershell
python adp_rs485_check.py --address 02
```

脚本会自动查找 CH340、CP210x 或 FTDI 等 USB-RS485 串口。如果自动查找失败，可手动指定：

```powershell
python adp_rs485_check.py --port COM5 --address 02
```

### 交互式吸排液

运行：

```powershell
python adp_rs485_interactive.py --address 02
```

终端中的操作顺序：

```text
ADP> init
ADP> tip
ADP> air
      // 将 Tip 移动到液面位置
ADP> asp
      // 吸液后将 Tip 抬离液面
ADP> tail
ADP> disp
ADP> disp
ADP> disp
ADP> flush
ADP> quit
```

命令含义：

| 命令 | 动作 |
|---|---|
| `init` | 初始化回原点 |
| `tip` | 查询 Tip 有无 |
| `air` | 在空气中执行首次回吸 30uL，Tip 不能放在液体里 |
| `asp` | 吸入 600uL，执行前请将 Tip 放入液体 |
| `tail` | 二次回吸空气，执行前请将 Tip 抬离液面 |
| `disp` | 排出 200uL（0.2mL），共执行 3 次 |
| `flush` | 排液至 0，最后清空 Tip |
| `status` | 查询运行状态 |
| `reset` | 重置当前吸排流程状态 |
| `quit` | 退出 |

脚本不会自动执行动作，只有输入 `air`、`asp`、`tail`、`disp` 或 `flush` 后才会发送相应指令。首次回吸必须在空气中执行，吸液时再将 Tip 放入液体。

## 7. 核心指令序列

以下示例地址为 `02`，CRC 已由脚本计算。实际使用时建议用脚本生成，避免手算错误。

| 步骤 | 指令 | 说明 |
|---|---|---|
| 查询版本 | `>02A93D8\r\n` | 确认通信正常 |
| 初始化 | `>02G9158\r\n` | 初始化回原点 |
| 轮询初始化 | `>02g4959\r\n` | 响应 `>02g01722E\r\n` 表示成功 |
| 查询 Tip | `>02q87D8\r\n` | 响应 `>02q01B6CF\r\n` 表示有 Tip |
| 设置吸液速度 | `>02401F43E2A\r\n` | 500 uL/s |
| 设置排液速度 | `>02B03E8C042\r\n` | 1000 uL/s |
| 设置首次回吸空气 30uL | `>02J001E00C800120C0001F403E84410\r\n` | 首次回吸空气量 |
| 首次回吸空气 | `>02M96D8\r\n` | 吸液前回吸空气 |
| 吸液 0.6mL | `>02n025806A7\r\n` | 600 uL |
| 二次回吸空气 | `>02P9F18\r\n` | 吸液后防 Tip 甩液 |
| 轮询动作 | `>02d4819\r\n` | 响应 `>02d0172DE\r\n` 表示完成 |
| 排液 0.2mL 第 1 次 | `>02p00C8A488\r\n` | 200 uL |
| 排液 0.2mL 第 2 次 | `>02p00C8A488\r\n` | 200 uL |
| 排液 0.2mL 第 3 次 | `>02p00C8A488\r\n` | 200 uL |
| 排液至 0 | `>02p000052AC\r\n` | 最后清空 Tip |
| 轮询动作 | `>02d4819\r\n` | 响应 `>02d0172DE\r\n` 表示完成 |

注意：上述 CRC 是按地址 `02` 计算的。若设备地址不同，CRC 必须重新生成。

## 8. 常用状态码

轮询 `d` 时可能返回以下状态：

| 状态码 | 含义 | 处理建议 |
|---|---|---|
| `00` | 运行中 | 继续轮询 |
| `01` | 运行完成 | 进入下一步 |
| `02` | 异常停止 | 停止连续发送动作 |
| `05` | 超过 ADP 可用容积/行程 | 检查吸液量、Tip 容量、活塞状态 |
| `06` | 吸液阻塞 | 发送 `p0000` 排液，必要时褪 Tip 更换耗材 |
| `07` | 排液阻塞 | 褪 Tip，检查堵塞或液体粘稠度 |
| `09` | 吸液空吸 | 确认 Tip 已进入液面后重新吸液 |
| `15` | 气路异常 | 检查 Tip、滤芯和内部气路 |
| `3D` | 温度异常 | 断电等待冷却 |
| `46` | 多次褪 Tip 失败 | 手工移除 Tip 后重新初始化 |

## 9. 操作注意事项

- 吸液前必须确认已经安装 Tip，且 Tip 容量不小于 0.6 mL。
- 首次上电后必须先初始化回原点。
- 吸液时不要让 Tip 扎入液面过深，避免外壁挂液。
- 如果排液后 Tip 口有挂液，可先发送 `M` 首次回吸空气，再执行吸液。
- 本脚本设置的速度参数只对本次上电生效，不会自动保存；如要保存，使用上位机或发送 `U` 保存参数。
- 当前串口被其他软件占用时，会打开失败，请先关闭大肯调试软件或确认 COM 口未被占用。

## 10. 如果改用 Modbus-RTU

使用 Modbus-RTU 时，关键寄存器如下：

| 动作 | 寄存器 | 写入值 |
|---|---|---|
| 初始化回原点 | `0x020C` | `0x0001` |
| 查询初始化状态 | `0x020D` | 读，`0x0001` 表示成功 |
| 吸液 0.6mL | `0x0222` | `0x0258` |
| 查询运行状态 | `0x0204` | 读，`0x0001` 表示完成 |
| 排液 0.2mL（重复 3 次） | `0x022B` | `0x00C8` |
| 设置吸液速度 | `0x0234` | 例如 `0x01F4` = 500 uL/s |
| 设置排液速度 | `0x0233` | 例如 `0x03E8` = 1000 uL/s |

Modbus 帧使用标准 CRC-16/Modbus，低字节在前、高字节在后。
